# portfolio_Chebitko

This repository presents selected programming work and coursework projects.

## Projects

- [First Aid AI - Module 1](./first-aid-ai/) - an AI-driven university full-stack project built with React and FastAPI, featuring verified registration, JWT sessions, AI-supported readiness assessment, editable medical profiles, password recovery, BigQuery integration, and deterministic fallback classification.
- [SCUDEM X 2025 - It Is Raining Space Dust](./scudem/) - an Outstanding Award mathematical-modeling project using coupled ODEs, atmospheric drag and ablation, RK45 simulation, and parameter sweeps to study cosmic-dust survival.
- [Algorithmic Programming in C++](./algorithmic-programming/) - 22 C++ solutions selected from 447 reviewed Grade 10 and Grade 11 coursework programs, showcasing dynamic programming, data structures, graph connectivity, number theory, geometry, bitwise techniques, search, and range queries.
- [C Programming Exercises](./c-programming/) - a topic-based collection of 19 C programs covering core language concepts, data structures, file operations, memory management, matrices, and sorting algorithms.

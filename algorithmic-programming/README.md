# Algorithmic Programming in C++

This folder presents 22 selected C++ programs completed during Grade 10 and Grade 11 coursework and competition preparation. After deduplication and syntax screening, 447 candidates were reviewed to select these representative programs.

## Selected areas

| Area | Programs | Techniques represented |
| --- | ---: | --- |
| `bitwise` | 2 | XOR-based recovery and fixed-width bit complementation |
| `brute-force` | 2 | Bounded enumeration and small-state simulation |
| `data-structures` | 3 | Stacks, reverse Polish notation, and frequency maps |
| `dynamic-programming` | 3 | State transitions, grid optimization, and path reconstruction |
| `geometry` | 2 | Circle-intersection area and point-in-triangle testing |
| `graph-connectivity` | 2 | Disjoint-set union and connectivity queries |
| `number-theory` | 3 | Prime sieves, GCD-based fraction reduction, and lattice points |
| `search-and-range-queries` | 4 | Binary search, two pointers, three-sum, and sparse tables |
| `strings` | 1 | Linear scanning for the longest repeated-character run |

Files have descriptive names and are grouped only by algorithm family.

# C Programming Exercises

This folder contains 19 C programs completed as part of programming coursework.

## Structure

- `fundamentals` contains exercises with arithmetic, mathematical functions, conditions, loops, and control flow.
- `arrays-and-strings` demonstrates array processing and standard string operations.
- `matrices` covers matrix addition, multiplication, and transposition.
- `data-and-memory` includes structures, dynamic allocation, and file-based employee records.
- `algorithms` contains sorting implementations and a coordinate-analysis exercise.
